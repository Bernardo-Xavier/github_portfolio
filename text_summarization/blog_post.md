## **What is Text Summarization?**

Text summarization is the process of condensing a large piece of text into a shorter version while retaining the key information and meaning. There are two main approaches:

1. **Extractive Summarization**: This method selects the most important sentences or phrases from the original text and concatenates them to form a summary. Think of it as highlighting the key points in an article.
2. **Abstractive Summarization**: This method generates new sentences that capture the essence of the original text. It’s more like rewriting the article in your own words.

For this project, I implemented both techniques to compare their strengths and weaknesses.

## **The Approach**

### **1. Extractive Summarization with TextRank**
I used the **TextRank** algorithm, a graph-based ranking model inspired by Google’s PageRank, for extractive summarization. Here’s how it works:
- Sentences are treated as nodes in a graph.
- Edges between nodes represent the similarity between sentences.
- The algorithm ranks sentences based on their importance and selects the top ones for the summary.

**Implementation**:
I used the `sumy` library to implement TextRank. It’s lightweight and works well for extracting key sentences from news articles.

```python
from sumy.summarizers.text_rank import TextRankSummarizer

def extractive_summary(text, sentences_count=3):
    parser = PlaintextParser.from_string(text, Tokenizer("english"))
    summarizer = TextRankSummarizer()
    summary = summarizer(parser.document, sentences_count)
    return " ".join([str(sentence) for sentence in summary])
```

---

### **2. Abstractive Summarization with BART**
For abstractive summarization, I used the **BART (Bidirectional and Auto-Regressive Transformers)** model from Hugging Face’s `transformers` library. BART is a pre-trained transformer model fine-tuned for text generation tasks like summarization.

**Implementation**:
I used the `pipeline` API from Hugging Face to load the BART model and generate summaries.

```python
from transformers import pipeline

def abstractive_summary(text, max_length=130):
    summarizer = pipeline("summarization", model="facebook/bart-large-cnn")
    summary = summarizer(text, max_length=max_length, min_length=30, do_sample=False)
    return summary[0]['summary_text']
```

## **Challenges Faced**

1. **Handling Long Articles**:
   - News articles can be very long, and transformer models like BART have a token limit (e.g., 1024 tokens). To address this, I split the text into smaller chunks and summarized each chunk separately before combining the results.

2. **Quality of Summaries**:
   - Extractive summaries can sometimes feel disjointed because they simply concatenate sentences. Abstractive summaries, while more fluent, can occasionally introduce inaccuracies or omit important details.

3. **Computational Resources**:
   - Abstractive models like BART require significant computational power. Running them on a CPU can be slow, so I recommend using a GPU for faster inference.
