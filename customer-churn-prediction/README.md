# Predictive Analytics for Customer Churn

This project aims to predict customer churn using machine learning algorithms. The dataset used is `customer_churn_dataset-testing-master.csv`.

## Project Structure
- `data/`: Contains the dataset.
- `notebooks/`: Jupyter Notebook for data exploration, preprocessing, and modeling.
- `models/`: Saved models and scaler.
- `README.md`: Project documentation.
