# LLM Question Answering System

This is a simple LLM-based question-answering system built using Langchain and deployed with Streamlit. It uses the RAG (Retrieval-Augmented Generation) method to answer questions based on a given text file.

## Setup

1. Clone the repository:

2. Install the required dependencies:
pip install -r requirements.txt

3. Run the Streamlit app:
streamlit run app.py

## Usage

1. Upload a text file.

2. Enter a question based on the content of the text file.

3. The system will generate an answer based on the content.

## Dependencies

1. Langchain

2. Streamlit

3. HuggingFace Transformers

4. OpenAI API
